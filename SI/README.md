Header Files of SI lib
======================


* all.h - includes all other header files (for convenience)
* datatypes.h - defines datatypes such as SI::length
* units.h - defines units such as SI::meters
* literals.h - defines literals such as 100_m
* constants.h - defines constants such as SI::constant::speed_of_light
* formulas.h - defines formula functions such as SI::formula::wavelength()
* conversions.h - defines conversion functions such as SI::to_string()
* print.h - contains simple print to console functions 
* tests.h - contains unit tests at compile-time to verify everything
